# Tanvo

Marketing site for Tanvo, a digital technology agency. React 19 + Vite + Tailwind CSS v4 + Framer Motion.

## Commands

```bash
npm run dev      # start dev server
npm run build    # production build to dist/
npm run preview  # preview the production build
npm run lint     # oxlint
```

## Structure

- `src/components/` — page sections (`Hero`, `Services`, `Work`, `Process`, `Technology`, `About`, `CTA`, `Contact`, `Footer`, …) and shared UI primitives in `components/ui/`
- `src/lib/data.js` — copy and content for services, projects, process steps, tech stack
- `src/lib/socials.js` — social links (currently placeholder URLs — update before launch)
